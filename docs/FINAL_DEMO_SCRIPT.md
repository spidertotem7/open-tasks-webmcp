# Final Demo Script

Target length: about 110 seconds.

## 0:00–0:12

“Tasks often appear while I'm already planning with ChatGPT. Normally I have to stop, open a task manager, and manually copy everything over. Open Tasks turns the task manager I already use into an agent-native workspace through WebMCP.”

## 0:12–0:30

“I can say, ‘Add Record launch trailer for Wednesday and make it high priority.’ ChatGPT invokes the app's structured create tool, and the task appears immediately in the real interface.”

## 0:30–0:45

“I can also ask what's overdue and what is due this week. The agent retrieves exact task records and stable IDs—no guessing from labels or DOM position.”

## 0:45–1:12

“The collaboration becomes more interesting when I use the interface and the agent together. I’ll select these two cards visually, then say, ‘Move these to Friday, but leave the launch trailer where it is.’ Page-aware context tells the agent exactly what ‘these’ means. It updates those selected tasks while leaving the trailer unchanged.”

## 1:12–1:28

“Now I’ll ask it to mark Draft launch newsletter complete. The app uses its normal completion path, and the task moves out of the active list immediately.”

## 1:28–1:42

“The human points and reviews visually. The agent understands intent and acts through validated tools. Both work in the same live task state.”

## 1:42–1:50

“Open Tasks is not another AI todo app. It is an existing task manager made agent-native with WebMCP.”
